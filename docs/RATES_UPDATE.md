# 年度料率の更新手順

給料計算の料率データはすべて `app/lib/payrollRates.ts` の1ファイルに
まとまっている。年度更新はこのファイルだけを編集すればよい。

## 自動更新タスク

毎年 **2月15日** に Claude の自動タスク「年度料率自動更新」が実行される:

1. 新年度の公式料率(協会けんぽ47都道府県・介護保険・雇用保険・
   子ども・子育て拠出金・税制改正)をWeb検索で収集し、複数ソースで
   照合する。
2. すべて確認できた場合: `rates-update-<年>` ブランチに更新を
   プッシュする。**mainには直接反映されない** — GitHub上で内容を
   確認し、公式の保険料額表と数値を照合してからマージすること。
   マージするとVercelが自動デプロイし、全端末に即時反映される。
3. 確認できない数値があった場合: 更新せず、確認済み/未確認の
   一覧が通知される。その場合は公式PDFをClaudeに渡して手動更新する。

実行結果はプッシュ通知とメールで届く。

## 手動更新のポイント

- `KENPO_HISTORY` に1年分のエントリを追加し、`KENPO_MAX_YEAR` を
  更新する(協会けんぽ料率は毎年3月分から適用)。
- 雇用保険料率が変わった年は `KOYO_PERIODS` の先頭に期間を追加
  (4月から適用。年度途中の改定にも期間追加で対応できる)。
- 子ども・子育て拠出金率が変わったら `kodomoRate` に分岐を追加。
- 税制改正で源泉徴収の電算機計算の特例が変わったら
  `calcWithholdingTax` / `kyuyoShotokuKojo` / `kisoKojo` に
  年分岐を追加する。
- 未登録の将来年度は自動的に最新年度の料率で計算され、画面に
  注意書きが表示される(アプリが止まることはない)。

## 検証方法

```bash
npm run build   # 型・ビルド確認
```

抽出テスト(標準報酬月額・折半・端数処理の確認):

```bash
node --experimental-strip-types --no-warnings -e "
import('./app/lib/payroll.ts').then(({ calcPayroll }) => { /* 計算例 */ });
"
```

数値の出典は必ず公式(協会けんぽ・日本年金機構・厚生労働省・国税庁)の
保険料額表と照合すること。
